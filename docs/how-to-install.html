Blender AI Copilot

How to install and test

Great, you can load and test it now. Follow these exact steps.

Blender 4.2+ is recommended. Keep the repository up to date before packaging the add-on. The backend default URL is http://localhost:3009.
1

Confirm Blender and the repo

Make sure Blender is installed (4.2+ recommended) and your repo is up to date.

2

Create an installable zip

From your project root, run:

cd /Users/ogunwolesamuel/development/projects/BlenderPluginAI/apps/blender_addon
zip -r blender_ai_copilot.zip blender_ai_copilot

Alternative from the repo root: python3 scripts/package_addon.py

3

Open Blender

Launch Blender 4.2 or newer.

4

Open Add-ons preferences

Go to Edit → Preferences → Add-ons.

5

Install from Disk

Click the dropdown at top-right (or Install...) and choose Install from Disk.

6

Select the zip

Select:

/Users/ogunwolesamuel/development/projects/BlenderPluginAI/apps/blender_addon/blender_ai_copilot.zip
7

Enable the add-on

Enable the add-on checkbox for Blender AI Copilot.

8

Open the plugin UI

  • 3D Viewport → press N → Copilot tab
9

Configure add-on settings

  • In the Copilot panel, click the settings icon
  • Set Backend Base URL to http://localhost:3009
  • Keep timeout/retry defaults unless needed
  • Enter a username and password, then click Authenticate / Log In
10

Start the backend

Start backend in another terminal:

cd /Users/ogunwolesamuel/development/projects/BlenderPluginAI
. ~/.nvm/nvm.sh
nvm use 22
npm run dev -w @blender-ai/backend
11

Test in Blender

Back in Blender:

  • Click Refresh Connection
  • Click Refresh Scene Context
  • Send a test message (for example: Hello)
